Ensembyte 1.1.15 — by Soumya Chakraborty. macOS Release.

## New features

### Floating HUD Panels: Independent Artifacts & Todos
- **Dedicated Floating Panels**: Split the task and artifact inspection interface into two independent, drag-and-drop HUD windows:
  - **Artifact Panel**: Floating inspector for all generated files, diffs, Markdown docs, and image outputs. Supports docking to edges, free-floating anywhere on screen, minimisation, and syntax-colored previews.
  - **Todo Panel**: Floating interactive checklist displaying live `.todos` tasks in real time with quick checkboxes, progress counters, and automatic dock-snapping.
- **Scene Collision Avoidance**: Both panels participate in the window layout engine, automatically repositioning and avoiding collisions when chat view sizes change or other panels dock.
- **Top Chrome Menu**: Quick toggle triggers for Todos and Artifacts directly in the Panels capsule menu in the chat header.

### Per-Thread WebKit Browser Isolation
- **Isolated Browser Sessions**: Browser panel visibility and multi-tab state are now scoped per thread. Switching conversations preserves or discards tabs cleanly without leaking web sessions across unrelated projects.
- **Direct Markdown Link Interception**: Clicking web or localhost documentation links generated in agent turns routes them directly into the docked in-app WebKit browser rather than launching an external application.
- **Enhanced Keyboard Shortcuts**: Added `⇧⌘B` shortcut hints in tooltip menus and omnibar helpers for terminal-speed web preview toggling.

## Refinements

### Window Chrome & Veils
- **Streamlined Top Veil Hierarchy**: Removed redundant top veil overlay constraints to improve scroll rendering smoothness and eliminate visual stacking artifacts during fast scrolling.
- **Panel Clamping on Resize**: Enhanced free-floating panel boundaries to guarantee panels stay fully inside the visible window area when resizing or entering Split View.
