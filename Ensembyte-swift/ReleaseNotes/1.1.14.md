Ensembyte 1.1.14 — by Soumya Chakraborty. macOS Release.

## New features

### Thread Working Modes: Single Agent, Panel, and Thread
- **Single-Agent Solo Mode**: Introducing Single-agent thread mode. When enabled, a lead agent works the thread directly using its own tools and capabilities without dispatching parallel Hydra heads. Standing delegation prompts instruct the model to execute work in-thread, suppressing unnecessary delegation blocks.
- **Three-Way Working Mode Selector**: Easily configure working mode per thread:
  - **Single agent**: One model handles the conversation and task execution solo with no secondary heads or panels.
  - **Heads in panel**: Parallel worker heads run and report through the floating head panel docked beside the chat.
  - **Heads in thread**: Parallel worker heads execute cleanly as nested subthreads within the sidebar timeline.
- **Quick Working Mode Menu**: Switch working modes instantly via the left-click menu on the Hydra mark or configure them directly in the updated Working Mode section of Settings.

### Live Thread Tasks & Artifacts Section
- **Docked Task & Artifact Section**: Added a collapsible bottom inspection section directly below the conversation thread with quick tabs for **Todos** and **Artifacts**.
- **Interactive Todos Tab**: Live checklist reading the turn's active `.todos` entries in real-time, showing in-flight and completed tasks with checkmarks and progress indicators.
- **Rich Artifacts Tab**: Split-view browser of all files created or modified by the agent. Includes syntax-colored diff hunks with inline additions/deletions counts, Markdown documentation renderers, and image previewers.
- **Panels Menu**: Toggle the Todos and Artifacts sections from the new Panels capsule menu in the chat header.

## Bug fixes

### Header Overflow & Title Truncation
- **Elastic Header Spacing**: Added an elastic spacer between the thread title and right-hand action capsules, ensuring long branch names and thread titles truncate cleanly with an ellipsis rather than pushing action buttons off-screen or clipping behind window corners.

## Refinements

### Settings & Provider Solo Handling
- **Provider Solo Integration**: Automatically passes solo thread mode flags to ACP, Codex, Command Code, and OpenAI-compatible provider sessions, preventing external subagents from spawning unexpectedly.
- **Settings Working Mode Card**: Added an interactive working mode card with visual pickers in Hydra Settings for quick inspection of the active thread's mode.
