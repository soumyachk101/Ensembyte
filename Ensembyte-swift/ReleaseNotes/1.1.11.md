Ensembyte 1.1.11 — by Soumya Chakraborty. macOS Release.

## Security & Architecture Hardening

### Workspace Secret Denylist & Path Protection
- **Unconditional Secret Filtering**: Added `WORKSPACE_SECRET_DENYLIST` denying access to sensitive files (`.env`, `.env.*`, `*.pem`, `id_*`, `credentials`, `*.key`, `*.p12`, `*.keystore`) across reads, writes, mutations, workspace directory listing, and fuzzy searches.
- **Diff Sync Leak Prevention**: Untracked patch captures in the engine now strictly filter denylisted secret files, ensuring secrets and credentials are never captured or broadcast across synced peers even when `includeIgnored` is enabled.

### Diff Sync Repair Throttling
- **Idle Tree Diff Throttling**: Added interval-based repair throttling (`REPAIR_MIN_INTERVAL`) with genuine filesystem watch tracking. Skips redundant, expensive git diff sweeps on quiet repositories while guaranteeing immediate re-capture as soon as file modifications arrive.

### Exited Terminal PTY Reaper
- **TTL-Based Buffer Reaping**: Improved PTY reaper lifecycle to reliably sweep terminated shell sessions and inert replay buffers after TTL expiration, preventing resource accumulation during long development sessions.

## Swift Core Improvements & Testing

### EnsembyteCoreTests Unit Test Target
- **Comprehensive Unit Testing**: Added native `EnsembyteCoreTests` bundle for macOS covering foundational models and utilities (`StdioFramer`, `ThreadContinuation`, `JSONValue`, `ISO8601`, `HydraCookbook`).
- **StdioFramer Memory Leak Prevention**: Fixed buffer retention on oversized frames (>16MB) by resetting internal framing state on failure (`failTooLarge`), preventing memory bloat and stale buffer poisoning.
- **Hydra Regex Performance & Hang Fix**: Statically cached compiled regexes in `HydraPrompts` with fast string checks, eliminating dynamic regex re-parsing and resolving UI/thread hangs during context continuation processing.
- **Continuation Ordering & Budget Preservation**: Ensured forwarded threads retain the initial user request at the context boundary, cleanly positioning omission markers when context budget constraints require intermediate turn trimming.

## CI & Dependency Hardening
- **Cargo Deny Automation**: Integrated license compliance and security vulnerability advisory checks across the Rust workspace in CI.
- **Workspace Member Pruning**: Isolated preview mobile crate from default workspace build targets.
