## Security & Identity

### Ensembyte[bot] Commit Attribution & Keychain-Backed App Signing
- **Co-Author Trailer Hooks (`CommitCredit.swift`, `Shell.swift`)**: Automatically installs `git-hooks` wrappers into `LoginEnvironment.current` via `GIT_CONFIG_COUNT`/`core.hooksPath` so agent commits invoke the repository's existing hooks first and append `Co-authored-by: ensembyte[bot] <352044576+ensembyte[bot]@users.noreply.github.com>`.
- **Unified Bot Identity (`GitHubAppIdentity.swift`)**: Centralizes Ensembyte App (`appId = 5597496`, `clientID = Iv23lip8dk91VWKI1t22`) and updates `botUserID` to `352044576` across both `Ensembyte-swift` and `Ensembyte-rust`, fixing attribution so GitHub resolves `ensembyte[bot]` accurately.
- **Per-Installation Bot Token Store & Keychain Override (`GitHubAppAuth.swift`, `GitHubSettingsSection.swift`)**: Replaces the single token slot with per-installation `BotTokenStore` caching (`[Int: BotTokenCache]`), adds an App Private Key Keychain override field in Settings, and cleanly separates `humanOverlay` from `botOverlay` in `GitHubConnection`.
- **Zero Plaintext Credential Fallbacks (`AppSettings.swift`, `GitHubAuth.swift`)**: Removes all `UserDefaults` plaintext fallbacks for provider API keys and GitHub tokens when Keychain writes are declined, keeps tokens strictly in memory (`keychainUnavailable`), lowers the `gh` CLI token cache TTL to 60s, and invalidates cached auth immediately on 401 responses.

### MCP & OAuth Hardening
- **Proactive OAuth Refresh (`MCPOAuth.swift`)**: Introduces `TokenDecision` (`.noRefresh`, `.refresh`, `.useStale`) so tokens lacking `expires_at` with an available `refresh_token` refresh proactively instead of being assumed valid indefinitely.
- **Bounded Proxy Response Reads (`MCPProxy.swift`)**: Caps non-SSE upstream MCP response bodies at 32 MiB (`bodyLimit`), returning `502` instead of allowing unbounded memory growth.

## Provider Stability & UI Architecture

### Provider Lifecycle & Reset Polling
- **Bounded Z.ai Reset Confirmation (`ZaiAPI.swift`, `PlanLimits.swift`)**: Replaces the fixed 2-second sleep after credit reset with bounded `confirmReset` polling against `credit-` windows and introduces `ResetOutcome.pending` when meter updates lag.
- **Watchdog Generation Guard (`ProviderRegistry.swift`)**: Tracks `limitsReadGeneration` per provider so slow `PlanLimitsReader` reads superseded by a watchdog timeout cannot overwrite fresher limits.
- **Bounded Copilot Teardown (`CopilotSession.swift`)**: Tracks shutdown and close-backstop tasks, capping `runtime.shutdown` at 2 seconds and cancelling in-flight teardown tasks cleanly on close or `deinit`.

### Chat Workspace Isolation, Tests & Cleanup
- **Per-Directory Git Status Caching (`ChatView.swift`)**: Scopes git status reads, in-flight request coalescing, 32-entry LRU snapshot caching, and activity tracking per directory so rapid workspace switching never mixes repository status.
- **Pure Panel Reorder Layout (`ReorderLayout.swift`)**: Extracts pure stack layout calculation out of `ChatView` and caches `PanelScene.autoPoppedIDs`, backed by new unit test coverage (`EnsembyteCoreTests`: 77 tests passing across `CommitCreditTests`, `GitHubBotTokenCacheTests`, `MCPOAuthTests`, `ReorderLayoutTests`, and `ZaiResetConfirmTests`).
- **Dead-Code Removal (`ThreadRuntime.swift`, `TimelineRows.swift`, `RootView.swift`)**: Removes unused views and redundant state (`DragHandle`, `HydraRunMetricsView`, `HydraDelegationBlock`, `OpenAICompatibleAPI`, `CopyCommandButton`, `AppZoomModifier`, `OrbTheme`, and `latestTodos`).
