Ensembyte 1.1.9 — by Soumya Chakraborty. Universal Release for macOS, Windows & Linux.

## New features

### WorkOS AuthKit & Cloud Sync Integration
- **Custom AuthKit Integration**: Fully integrated WorkOS AuthKit for seamless desktop user sign-in and cross-device session synchronization.
- **Local Loopback Callback Listener**: Secure OAuth loopback listener (`http://127.0.0.1:27641/callback`) with automated authorization code exchange.
- **Dynamic Edge Authentication Routing**: Replaced legacy endpoints with unified serverless authentication routes hosted on `https://ensembyte.vercel.app`.

### High-Resolution Vector Branding & Motion Loaders
- **Refreshed Vector Icon**: High-definition 1024×1024 vector brand artwork embedded in `dist/ensembyte.svg` for crisp rendering across all display DPI scales.
- **Thinking Shader Orb**: Animated multi-gradient rotating shader orb with live duration tracking and dynamic tier indicators.
- **Interactive Test Results**: Integrated test report protocol and test runner view with AI error resolution assistance.

## Refinements

### Authentication Stability & Clean Offline Handling
- **Workspace Scope Indicator**: Real-time user avatar and account profile menu in the sidebar footer with instant status updates upon login.
- **Graceful Local Fallback**: Seamless fallback to local workspace mode when offline or unauthenticated.
