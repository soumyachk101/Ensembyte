Ensembyte 1.1.7 — by Soumya Chakraborty. Universal Release for macOS, Windows & Linux.

## New features

### GitHub Repository Integration & Direct Cloning
- **Welcome Screen GitHub Clone**: Direct "Clone from GitHub" button positioned alongside "Add a project" on the initial welcome view.
- **Sidebar Add Project Popover**: Contextual quick menu on the sidebar's "Add project" button offering both local directory selection ("Choose a folder…") and GitHub cloning ("Clone from GitHub…").
- **Menu Bar & Command Palette Shortcuts**: Added `File › Clone from GitHub…` to the main menu bar and a searchable "Clone from GitHub" item in the Command Palette (`⌘K`).

### AppZoom Window Menu Shortcuts
- **Zoom In / Out / Actual Size**: Direct keyboard shortcuts (`⌘+` / `⌘=` to Zoom In, `⌘-` to Zoom Out, and `⌘0` for Actual Size) added to the Window menu for quick whole-app UI scaling.

## Refinements

### Multi-Architecture Release Support
- **Apple Silicon & Intel Disk Images**: Upgraded release automation to build, sign, and notarize dedicated `arm64` and `x86_64` disk images (`Ensembyte-1.1.7-arm64.dmg` & `Ensembyte-1.1.7-x86_64.dmg`), plus universal `Ensembyte.dmg`.
- **In-App Architecture Detection**: Update checker automatically detects the host Mac architecture and downloads the matching single-architecture build.
