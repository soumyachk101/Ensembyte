Ensembyte 1.1.4 — by Soumya Chakraborty. Apple silicon, macOS 26 or later.

## Major New Features

### Voice Mode & Interactive Orb
- **Live Voice Interaction**: Converse naturally with coding models using voice mode, powered by `LocalDictationEngine` and real-time audio synthesis.
- **Liquid Glass 3D Orb Visualizer**: Interactive shader-driven particle orb that responds in real-time to speech, listening state, and thinking transitions.
- **Composer Dictation**: Built-in voice input trigger directly in the chat composer for hands-free prompt dictation.

### Redesigned Dynamic Model Picker
- **Provider Icon Rail**: Split-layout model picker with a vertical provider rail and tile highlight, showing model counts dynamically for each provider in the header.
- **Instant Search**: Real-time filtering across all installed providers and models by name, short name, or identifier.
- **Mid-Session Model Switching**: Change models or switch providers at any point in an ongoing chat without lockout. Subsequent turns seamlessly adapt.

### Multi-Account & Provider Management
- **Multi-Account Switching**: Manage and switch between multiple accounts per provider directly in Settings and the Usage pane.
- **Automated CLI Updates**: In-app checker and updater for installed agent CLIs to ensure full compatibility with the latest provider models.
- **OMP Provider Integration**: Full native support for OMP provider sessions, plan limits, and command execution.

### GitHub Integration & Repository Cloning
- **GitHub Device Connect**: Direct GitHub account authorization with secure macOS Keychain storage.
- **Repository Clone Panel**: Clone and open GitHub repositories directly from within Ensembyte.

### Timeline, Stream & UI Enhancements
- **Activity Tree**: Structured hierarchical view of tool executions, shell commands, and subagent turns.
- **App-Wide Zoom**: Configurable UI scaling across the entire application interface.
- **Custom Terminal Typography**: Configurable font selection and line heights for terminal buffers and code views.
- **120 FPS Timeline & Stream Mending**: Smoother message streaming transitions and link preview hovers.
