Ensembyte 1.1.5 — by Soumya Chakraborty. Universal Release for macOS, Windows & Linux.

## Highlights & New Features

### Voice Mode & ChatGPT Session Refresh (macOS)
- **Codex Voice Token Refresh**: Automatically refreshes authentication tokens on `account/read` (`refreshToken: true`), eliminating premature voice session timeouts and false `chatgptRequired` rejections during active sessions.
- **Realtime Host Connection**: Hardened realtime connection recovery and voice catalog listing across long-running background sessions.

### Native Embedded WebView2 Browser (Windows)
- **Windows WebView2 In-App Browser**: Native browser component powered by WebView2 (`webview2-com` + `windows-core`), featuring an isolated visual hosting surface and seamless pointer event forwarding.
- **Sanitized Brand & IPC**: Full Ensembyte brand isolation and clean IPC bridging (`ensembyte-webview2`, `ensembyte://`).

### Windows Drive & Path Navigation (Windows)
- **Drive Roots & Extended Paths**: Comprehensive support for drive roots (`D:\`), extended win32 paths (`\\?\D:\`), and UNC network shares.
- **Case-Insensitive Root Handling**: Case-insensitive drive prefix comparisons in project and directory pickers without altering POSIX paths.

### Security Hardening (Windows & Linux)
- **UNC & SMB Path Traversal Protection**: Lexical component jailing (`lexical_components()`) before filesystem calls to prevent UNC path traversal and block Windows NTLM credential leak vulnerabilities.

### Shell & Navigation Enhancements (Cross-Platform)
- **5-Button Mouse Navigation**: Back and forward route history traversal with Mouse 4 and Mouse 5 across shell views, thread history, and embedded browser surfaces.
- **Git Push Remote Fallback**: Graceful automatic fallback from disabled push URLs (`DISABLED--push-...`) to fetch URLs.

### Engine Performance & Linux Optimizations
- **Tokio Worker Thread Protection**: Disk chunk reads offloaded to `spawn_blocking` to prevent worker thread starvation.
- **MCP Bridge Worker Cap**: Bounded MCP bridge runtime to 2 worker threads.
- **Linux Glibc Malloc Trimming**: Periodic `malloc_trim` calls to release unused resident heap pages and cap idle RSS in long-running headless engine processes.
