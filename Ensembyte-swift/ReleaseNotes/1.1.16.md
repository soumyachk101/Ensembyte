Ensembyte 1.1.16 — by Soumya Chakraborty. macOS Release.

## New features

### Interactive Timeline Tasks & Live In-Flight Tracking
- **Interactive Task Checklist (`TodoCard`)**: Embedded directly in the chat timeline with real-time status indicators, dynamic progress bar, and live execution timer.
- **In-Flight Tool Call Following**: Active steps track running agent tools dynamically as they execute, displaying sub-activities and granular status.
- **Auto-Folding & State Preservation**: Folds completed steps automatically past 6 items to keep current work in focus; retains expanded row states across in-place list rewrites.

### Hydra Multi-Agent Activity & Head Lifecycle
- **Activity Group Overview**: High-efficiency grouped view of lead threads and their active subagents (`HydraActivityGroup`), keeping active agent heads front and center.
- **Watchdog State Pruning**: Automatically prunes stale monitoring state and idle watchdog entries when heads finish, stop, or are deleted.

### High-DPI Glyph Cache & Markdown Rendering
- **Unified Glyph Cache (`GlyphCache`)**: Centralized rasterization and multi-scale caching for template and tinted dragon head glyphs across Markdown and AppKit link paragraphs.
- **Link Routing & Typography**: Refined inline link paragraph layout with crisp icon alignment and responsive hover feedback.

## Architecture & Performance

### Non-Blocking Asynchronous Storage Architecture
- **Main-Actor Isolation**: Upgraded thread and turn storage access to async non-blocking queues (`readDocument`, `readRecentDocument`, `readTurns`), eliminating UI stalls during large thread deserialization.
- **Clean Layered Attachment Bridge**: Relocated composer attachment binding to `Storage+Attachments.swift` in the App layer, enforcing one-way dependency boundaries.

### Git Resiliency & Non-Blocking GitHub Auth
- **Safe Patch Truncation**: Truncates working tree diff patches strictly at top-level file diff boundaries (`diff --git `), preventing corrupted hunks during checkpoint generation.
- **Async GitHub Token Warming**: Main-thread safe cached authentication token queries with background utility warming (`warmCache`, `cachedToken`).
- **Git Lane Discipline**: Classifies mutating operations like `commit` and `clean` into dedicated checkpoint execution lanes.

### In-App WebKit Browser Optimizations
- **Background Tab Pause/Resume**: Automatically pauses in-flight tab loads when the browser section is hidden, resuming cleanly when reopened to save memory and battery.
- **Thread Safety**: Hardened thread validation ensuring browser tabs only bind to active threads without creating orphaned page records.
