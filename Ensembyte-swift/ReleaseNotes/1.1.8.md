Ensembyte 1.1.8 — by Soumya Chakraborty. Universal Release for macOS, Windows & Linux.

## New features

### Interactive Pro Diff Review & Split Inspector
- **Unified & Split View Modes**: Added seamless toggle between classic unified diff view and side-by-side split diff view with synchronized vertical scrolling and column dividers.
- **Word / Token-Level Intra-Line Highlights**: Pinpoint highlighting for character- and word-level modifications within edited lines.
- **Inline Commenting & AI Feedback**: Hover comment action on any diff line allowing users to leave inline notes (`Regarding <file>:<line>: <feedback>`) that route directly into the chat prompt draft for instant AI revision.
- **File Action Cards & Bulk Controls**: Individual file action cards with status badges (`Added`, `Modified`, `Deleted`), addition/deletion counters, `✓ Accept` toggles, `✕ Revert File` actions, and top-bar `Accept All` / `Revert All` controls.

### Smart Chat Thread Auto-Scroll
- **Active Stream Auto-Tracking**: Chat timeline now continuously and smoothly auto-scrolls to the bottom during live message streaming, thinking block expansion, and tool execution.
- **User-Centric Scroll Pause**: Automatically pauses auto-scrolling when the user scrolls up to read earlier responses, and smoothly re-engages bottom tracking when scrolled back down.

## Refinements

### Diff Viewer Performance & Cache Management
- **Instant Revert & Cache Invalidation**: Reverting modified files flushes diff caches immediately so changes reflect instantly in the UI.
- **Expanded Popover Geometry**: Increased popover dimensions to 780×580 for spacious, high-fidelity side-by-side split review.
