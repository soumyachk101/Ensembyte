Ensembyte 1.1.20 — by Soumya Chakraborty. macOS Release.

## New features

- **Hydra Turn Budgeting & Dual-Clock Attribution (`AppModel+Hydra.swift`, `ThreadRuntime.swift`, `Hydra.swift`)**: Head cards and persisted history now accurately distinguish whether a head was stopped by watchdog stall or by turn budget exhaustion (`HydraBudget.stoppedNote`), replacing misleading activity labels and ensuring clear diagnosis in multi-agent runs.
- **Git Working Tree Inode Rewrite Detection (`WorkingTreeWatch.swift`)**: The working tree watcher now captures filesystem inode identifiers (`.fileIdentifierKey`), detecting Git index file rewrites even when file size and mtime are identical.
- **Provider Connection Crash Teardown & Approval Drainage (`ACPSession.swift`, `ClaudeSession.swift`, `CodexSession.swift`)**: Automatically resolves stranded tool approvals, drops orphaned permission requests, marks active turns/heads as failed, and reconciles archive confirmation on unexpected connection drops.

## Bug fixes

- **Provider Credits Read-Generation Guards (`ProviderRegistry.swift`, `ProviderRegistry+Accounts.swift`, `ProviderRegistry+CLIUpdates.swift`)**: Guarded credits and plan-limits reading with atomic generation sequences and a 25-second watchdog timer, preventing slow out-of-order balance fetches from overwriting newer post-spend balances.
- **Tree Walk Double-Generation Verification (`WorkingTreeWatch.swift`)**: Enforces pre- and post-walk generation verification during tree captures, discarding race-condition snapshots when background Git writes occur mid-walk.
- **Capture Run Hydra Suppression (`AppModel+Hydra.swift`)**: Ensures capture runs (`CaptureRun.isEnabled`) do not spawn real background worktrees or alter disk state, keeping automated tours and captures isolated.

## Refinements

- **Unified Quiescence Core (`ThreadRuntime.swift`)**: Consolidated dispersed idle, revert, prompt-queue, and Hydra batch checks into a single canonical `isQuiescent` property used by archiving, merge readiness, and auto-continuation.
- **IDE Empty State Polish (`IDESectionView.swift`)**: Added empty workspace fallback guidance with direct project opening controls, improved tab selection indicators, and refined diff drawer toggling.
