Ensembyte 1.1.19 — by Soumya Chakraborty. macOS Release.

## New features

- **IDE Mode (`Ensembyte/App/Views/IDE/`, `Ensembyte/Services/IDE/`)**: A third 'IDE' column beside the chat, toggled from the chat chrome row — a file tree with a filter field and per-type icons, an editable code view with unsaved markers and Cmd-S save, and a working-tree Changes tab with live diffs.
- **Agent-edit Safety in the IDE Editor (`IDEEditorStore.checkDiskDrift`)**: Open buffers track the disk state of their file; when an agent rewrites a file mid-edit a banner offers 'Reload' or 'Keep my edits', and clean buffers silently follow the agent's writes.
- **Terminal Tab in the IDE Pane (`IDESectionView+Terminal.swift`)**: The thread's own shell hosted beside the code, shared with the chat's bottom terminal, with a Restart control and an exited-shell placeholder.
- **Pane State Survives Relaunch (`IDEEditorStore+Persistence.swift`)**: Open files, selection and dirty flags persist under Application Support.

## Bug fixes

- **Model Picker Fable Deduplication (`ProviderRegistry.swift`, `CommandCodeAPI.swift`)**: The seeded Fable row and the live CLI catalog now fold into one Fable 5.2 entry instead of showing two Fable models; old 'claude-fable-5-1' ids (threads, captures, Command Code tables) resolve to 5.2 through an alias.

## Refinements

- **Fable 5.2 Naming (`HydraCookbook.swift`, `TourCaptures.swift`)**: Hydra cookbook recipes and tour captures now name Fable 5.2 instead of 5.1.
- **IDE Status Details (`IDESectionView.swift`)**: The Changes tab shows a total +N / -M summary over the changed-file list, and the editor carries a language/line-count status bar.
