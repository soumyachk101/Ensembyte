Ensembyte 1.1.17 — by Soumya Chakraborty. macOS Release.

## New features

### Ensembyte[bot] GitHub App Native Authentication
- **Native RS256 JWT Generation (`GitHubAppAuth.swift`)**: Generates and signs GitHub App authentication JSON Web Tokens directly using Apple's Security framework (`.rsaSignatureMessagePKCS1v15SHA256`) with zero third-party cryptography dependencies.
- **Dynamic Installation Token Minting (`GitHubConnection.swift`)**: Authenticates against GitHub App REST endpoints to mint and rotate short-lived (1-hour) installation access tokens, supporting private repository operations and automated workflow dispatch.
- **GitHub Connection Management**: Integrated `GitHubConnectView` and `GitHubSettingsSection` modal flows in Settings to verify credentials, inspect installation IDs, and test connection statuses.

### Chat Chrome & Artifacts HUD Direct Access
- **Direct Artifacts HUD Toggle (`ChatView.swift`)**: Upgraded top window chrome button from generic "Panels" to a dedicated **Artifacts** toggle with checklist iconography, smoothly opening the floating inspector via `runtime.isArtifactPanelVisible.toggle()`.

## Architecture & Performance

### Monospace Character Advance Validation in Terminal
- **Fixed-Pitch Grid Integrity (`TerminalFont.swift`)**: Enforces `picked.isFixedPitch` checks during font selection to prevent non-monospaced fallback fonts from distorting SwiftTerm character cell widths and horizontal layout grids.
- **Nerd Font Glyphs via CoreText**: Preserves Nerd Font glyph fallback through SwiftTerm's CoreText fallback pipeline while guaranteeing strict monospace baseline alignment.

### Credential Registry Hardening
- **OpenCode Zen Identifier Isolation (`ProviderRegistry.swift`)**: Enforces exact match against `"opencode"` (`localizedCaseInsensitiveCompare("opencode") == .orderedSame`), eliminating credential collision with OpenCode Go and other provider tokens.

### Cross-Platform UI Engine Stability
- **Windows WebView Composition Abstraction (`windows_webview.rs`, `view.rs`)**: Introduced layout-compatible local composition handles in Ensembyte-rust, resolving GPUI native composition compilation blockers on Windows and Linux targets.
