Ensembyte 1.1.1 — by Soumya Chakraborty. Apple silicon, macOS 26 or later.

## New features
- **Working line default**: The default working line style in Conversation settings is now set to a clean line ("Line") instead of "Card".
- **Hydra thread-mode indicators**: Live rotating working word tickers, animated mini thinking spinners, persona glyphs, and smooth spring physics transitions for child heads in the sidebar.
- **Dynamic platform landing page**: Website now automatically detects the user's OS (macOS, Windows, Linux) and dynamically updates platform highlights, hero text, and call-to-actions.

## Bug fixes
- Stabilized Swift CodeQL build workflow and updated codeql-action to v4.
- Resolved Rust clippy warnings and restored backward-compatible environment variable fallbacks.
